# 수학 클래스 RPG 웹앱 1차 개발 계획

## 목표

교사가 실제 교실형 모둠 배치판을 보면서 학생·모둠 MP, 스킬, 피버 타임, 역할과 승급을 관리한다.

## 1차 포함

- 교사 이메일 로그인
- 학급 생성
- 학생 명단 일괄 등록
- 6모둠 × 4자리
- 드래그 앤 드롭 배치와 학생 간 자리 교환
- 역할: 입문자, 수제자, 수승님, 상급 수승님, 수호자
- 담당 수승님 연결
- 수업 시작·종료
- 개인 +1/+2/직접 MP
- 모둠 전원 +1/+2 MP
- 역할별 스킬
- 중복 배율 계산
- 주 1회 피버 타임
- 거래형 MP 기록과 취소
- 20MP 승급
- 새 운영 기간과 과거 기록 보존

## 1차 제외

- 학생 로그인·개인 페이지
- 학생 PIN
- 순위 공개
- 승급 애니메이션
- 칭호
- 학생 알림
