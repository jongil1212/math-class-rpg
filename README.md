# 수학 클래스 RPG · 교사용 웹앱 (시즌 2)

2학기 수학 모둠활동을 위해 만든 **교사용 관리 웹앱 MVP**입니다.

핵심 목표는 다음과 같습니다.

- 실제 교실과 비슷한 `6모둠 × 4자리` 배치판
- 학생 카드 드래그 앤 드롭 및 자리 교환
- 개인·모둠 MP 빠른 지급
- 역할별 스킬 기록과 MP 계산
- 피버 타임 10분 자동 2배
- 모든 MP 내역 저장 및 취소 기록 보존
- 시즌 1 MP 승계와 누적 20·40MP 승급 처리
- 시즌 2 전용 스킬·공격 방어·발표 효과 관리
- 교사 개폐형 MP 상점과 사용권 구매·승인·환불
- 중간고사 이후 새 운영 기간 생성 및 과거 기록 보존

학생용 로그인·조회 페이지와 승급 애니메이션은 포함하지 않습니다.

### 3-2. 데이터베이스 만들기

Supabase 대시보드의 **SQL Editor**에서 아래 파일을 번호 순서대로 전체 실행합니다.

```text
supabase/migrations/001_initial_schema.sql
supabase/migrations/002_passive_mentor_grace.sql
supabase/migrations/003_auto_seating_mentors.sql
supabase/migrations/004_reset_class_mp.sql

supabase/migrations/007_bulk_role_assignment.sql
supabase/migrations/008_teacher_fever_time.sql

```

이 파일들은 다음을 생성합니다.

- 학급, 학생, 운영 기간, 모둠 배치
- 수업 세션, MP 기록, 스킬 사용, 승급 기록
- RLS 보안 정책
- MP 지급·취소·피버 타임·승급용 RPC 함수
- 1↔4, 2↔3 좌석 관계에 따른 `수승의 은혜` 자동 MP 지급
- 배치와 역할 변경 시 담당 수승님 관계 자동 동기화
- 기존 거래 기록을 보존하는 학급 MP 전체 초기화
- 수호자와 3인 모둠까지 포함하는 `수승의 은혜` 확장 규칙
- 학년도별 학급 구분과 학급·운영 기간 수정, 보관, 복구, 영구 삭제
- 학생 카드 다중 선택과 역할 일괄 설정
- 수호자 요청·교사 선언 피버 타임 구분과 사용 이력 보존

기존에 001~008을 실행한 프로젝트는 SQL Editor의 새 쿼리에서 `009_season_two.sql`만 전체 실행한 뒤 화면 코드를 배포합니다. 기존 데이터를 삭제하거나 001~008을 다시 실행할 필요가 없습니다. GitHub에 SQL 파일을 업로드하는 것만으로는 데이터베이스에 적용되지 않습니다.

## 7. 역할과 스킬

### 입문자

- 초심자의 행운: 발표 성공 MP 2배, 수업당 1회
- 현재 역할에서 20MP 획득 시 수제자 승급

### 수제자

- 매의 눈: +2MP
- 재도전: MP 없이 사용 기록, 수업당 1회
- 구원투수 도움받음: +1MP

### 수승님

- 수승의 은혜: +1MP
- 구원투수: 수승님과 연결된 학생 각각 +1MP
- 현재 역할에서 20MP 획득 시 상급 수승님 승급

### 상급 수승님

- 수승의 은혜: +1MP
- 구원투수: 각각 +1MP
- 매의 눈: +1MP
- 수승의 예언: +2MP

### 수호자

- 포기란 없다!: +1MP
- 수호자 요청 피버: 학급당 주 1회, 교사 승인 후 10분간 모든 MP 2배

### 교사 선언 피버 타임

- 수업 시작 후 상단의 `교사 선언 피버` 버튼으로 실행합니다.
- 수호자가 없는 학급에서도 10분간 모든 MP가 2배가 됩니다.
- 교사 선언은 횟수 제한이 없으며, 수호자 요청의 주 1회 사용 횟수와 별도로 기록됩니다.
- 두 방식 모두 진행 중에는 중복 시작할 수 없습니다. 10분 경과 또는 `피버 종료` 후 다시 시작할 수 있습니다.
- 수호자 요청의 주간 기준은 한국 시간 월요일 00:00부터 다음 월요일 00:00 전까지입니다. 이전 버전의 피버 기록은 수호자 요청으로 유지됩니다.

## 8. MP 계산 원칙

```text
모둠 활동 점수 1점 = 모둠원 전원 +1MP
개인 활동 점수 1점 = 해당 학생 +1MP
```

모든 배율은 중복 적용합니다.

```text
발표 성공 +1MP × 초심자의 행운 2배 × 피버 타임 2배 = +4MP
```

수승의 은혜와 수승의 예언도 각각 모두 지급할 수 있습니다.

---

## 9. 데이터 보존 원칙

- MP 합계를 직접 덮어쓰지 않고 모든 거래 내역을 저장합니다.
- 잘못 지급한 MP는 삭제하지 않고 반대 거래를 생성해 취소합니다.
- 중간고사 이후 새 운영 기간을 만들 때 기존 배치와 역할을 복사하거나 빈 배치로 시작할 수 있습니다.
- 모둠과 역할이 바뀌어도 학생의 누적 MP는 유지됩니다.
- 시즌 1에서 새 역할을 직접 지정하면 그 시점의 누적 MP부터 새 20MP 성장을 시작합니다. 시즌 2에서는 누적 MP 자체로 성장하며 역할 변경으로 성장 MP를 초기화하지 않습니다.

## 11. 현재 1차 버전의 제한

- 한 교사가 자신의 학급을 관리하는 구조입니다.
- 학생용 페이지는 없습니다.
- CSV 파일 자체 업로드 대신 명단 복사·붙여넣기를 우선 구현했습니다.
- 수호자 요청 피버의 주간 사용 여부는 서버에서 최종 검증합니다. 같은 학급의 다른 수업에서 이미 사용했다면 시작 요청 시 안내 오류가 표시됩니다. 교사 선언 피버에는 이 제한이 적용되지 않습니다.
- 구원투수 대상이 여러 명이면 간단한 확인창으로 대상 학생을 고릅니다.
- 승급 칭호는 표시되며 승급 애니메이션은 없습니다.
- 전화위복·강탈·듀오 캐스팅·상점 발표권의 실제 수업 진행 순서는 교사가 관리합니다. 자동 발표 순서표나 학생용 화면은 없습니다.

## 13. 시즌 2 시작과 운영

1. 먼저 `009_season_two.sql`을 Supabase SQL Editor에서 전체 실행합니다.
2. 화면 코드를 GitHub에 올려 Vercel 배포가 완료되면 새로고침합니다.
3. 진행 중인 수업을 종료하고, 기존 시즌 1을 선택한 상태에서 `새 운영 기간`을 누릅니다.
4. 규칙은 `시즌 2`, `현재 배치·역할을 복사해서 시작`을 체크한 상태로 새 기간을 만듭니다. MP는 복사 선택과 관계없이 유지됩니다.
5. 학생 카드에서 누적 MP를 확인하고 필요한 승급 버튼을 누릅니다.

| 계열 | 첫 승급 | 두 번째 승급 | 상점 성장 확보 MP |
| --- | --- | --- | --- |
| 입문자 → 수제자 → 상급 수제자 | 누적 20MP | 누적 40MP | 40MP |
| 수승님 → 상급 수승님 → 수학의 성인 | 누적 20MP | 누적 40MP | 40MP |
| 수호자 | 없음 | 없음 | 30MP |

35MP 수제자는 시즌 2에서 5MP를 더 얻어 상급 수제자로 승급할 수 있습니다. 승급은 교사가 버튼으로 확정합니다. 승급 시 누적 MP를 실제로 차감하지 않으며, 성장 확보 MP를 제외한 잔액만 상점에서 사용합니다.

### 스킬

- 상급 수제자: 기존 수제자 스킬 + **듀오 캐스팅**(같은 모둠 추가 발표자 1명) + **흡수의 일격**(완벽한 발표 후 다른 모둠 수승님에게서 1MP 이동).
- 수학의 성인: 기존 수승님·상급 수승님 스킬 + **전화위복**(공격으로 MP 손실 시 다음 활동 발표 최우선권) + **강탈**(다른 학생의 발표 기회 가져오기).
- 수호자: 기존 스킬 + **수호자의 가호**(자기 모둠의 다음 공격 1회 방어).
- 시즌 2 액티브 스킬은 스킬별 수업당 1회입니다. 구원투수 도움받음은 상대 스킬의 보상이므로 횟수 제한에서 제외합니다. 패시브 수승의 은혜도 횟수 제한이 없습니다.
- 흡수의 일격은 정확히 1MP를 이동하며 피버 배율·수승의 은혜를 추가로 발동하지 않습니다. 대상 MP가 0이면 사용하지 못하고 사용 횟수도 유지됩니다.
- 가호에 막힌 공격은 공격자의 사용 횟수와 가호 1회를 모두 소모합니다. MP 손실이 없으므로 전화위복도 발동하지 않습니다.
- 전화위복은 잘못 지급한 MP의 취소나 상점 구매로 발동하지 않습니다. 새 칭호에도 4→1 / 3→2 / 3인 모둠 2·3→1 관계가 유지됩니다.
- 수업 효과 목록에서 실제 발표를 진행한 뒤 `진행 완료`를 누릅니다. 수업 종료·새 수업 시작 시 남은 발표 효과와 보호는 승계하지 않습니다.

### 상점

| 상품 | 가격 |
| --- | --- |
| 발표 1회 우선권 | 2MP |
| 피버타임 요청권 | 4MP |
| 선생님의 힌트권 | 4MP |
| 간식 뽑기권 | 5MP |
| 수업 10분 조기 종료권 (반 전체) | 20MP |

구매 가능 MP = `max(0, 누적 MP − 성장 확보 MP − 환불되지 않은 구매 합계)`입니다. 구매로 누적 MP나 칭호를 낮추지 않습니다. 성장 확보 기준은 **첫 구매 시 역할에 따라 고정**하여 역할 변경으로 구매 가능 MP가 계속 달라지지 않게 합니다. 다음 시즌에도 기준·지출·미사용권을 승계합니다.

교사가 `상점 열기/닫기`로 주 1회·격주 등 원하는 날에만 운영합니다. 닫힌 상점에서도 미사용권의 사용 승인·환불은 가능합니다. 구매와 실제 사용을 분리하며, 요청을 보류하면 미사용 상태로 유지합니다. 사용 승인에는 진행 중인 현재 시즌 2 수업이 필요합니다.

- 발표권·힌트권·뽑기권은 실제 제공한 뒤 사용 승인으로 기록합니다.
- 피버 요청권 승인 시 교사 선언 피버 10분을 바로 시작합니다. 수호자가 없어도 가능하고 수호자 주간 횟수를 소모하지 않습니다. 피버가 이미 켜져 있으면 승인하지 않고 사용권을 유지합니다.
- 조기 종료권은 반 전체에 적용하는 것으로 승인·기록하며, 수업 타이머를 자동 종료하지 않습니다.
- 미사용권만 환불할 수 있습니다. 사용한 권리는 환불할 수 없습니다. 운영 기간을 삭제해도 구매 이력과 사용권은 학생에게 남습니다.
- 상점 구매 기록이 있으면 `MP 전체 초기화`를 제한합니다. 테스트 미사용권은 먼저 환불해야 하며, 사용 완료 구매가 남아 있으면 초기화할 수 없습니다. 시즌 전환에는 초기화 버튼을 사용하지 않습니다.
